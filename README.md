## 🚀 How To Run Each Project

Each project folder has its own `README.md` with full compile and run instructions.
Navigate into the project folder and follow the steps there.

### Example: Running Tic Tac Toe (miniProGame0)
```bash
cd miniProGame0
javac TicTacToe.java
java TicTacToe
```

### Example: Running File Download Manager (miniProject6)
```bash
cd miniProject6/File\ Download\ Manager\ System
javac -d bin src/Main.java src/com/downloader/*.java
java -cp bin Main
```

## 📌 Project Descriptions at a Glance

### 🎮 **miniProGame0** - Tic Tac Toe
A classic two-player 3x3 grid game with win detection, draw conditions, and input validation.

### 🧩 **miniProGame1** - Memory Game
Card-matching game with multiple difficulty levels (Easy/Medium/Hard) and move tracking.

### 📚 **miniProGame2** - Library Management System
System for managing books and student records with add/remove/view operations.

### 🧠 **miniProGame3** - Online Quiz App
Interactive MCQ quiz application with score tracking and service-based architecture.

### 🛒 **miniProGame4** - Inventory Management System
Inventory system for adding, removing, and viewing items with proper encapsulation.

### 🎬 **miniProject5** - Movie Ticket Booking System
Complete ticket booking system with movie selection, showtime management, and booking tracking.

### 📥 **miniProject6** - File Download Manager
Multi-threaded file downloader using ExecutorService for concurrent downloads with URL validation.
